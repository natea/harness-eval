Brownfield track pilot · static snapshot

Most real agent work is fixing an issue in a codebase the agent didn't write. Each trial here replays a real merged PR: the framework gets the issue as it stood before the fix, the PR's own tests stay hidden until grading, and a blind judge compares the result with the original PR.

Every trial — newest first; click a row for the judge's scores and both diffs

People check the tasks first

Before a task runs, a reviewer labels how much of the fix each issue and comment gives away, without seeing the LLM's labels, and says whether the hidden tests are fair. The two sets of labels are then compared.
