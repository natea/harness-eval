## Discussion

**@dosubot** (2025-07-24):

<!-- Answer -->
The deprecation warning is misleading: while it says to move paper_directory to AgentSettings, AgentSettings does not accept this field directly, which is why you see the validation error. The correct way (in v5.24.0 and v5.25.0) is to set paper_directory inside IndexSettings, which is then passed to AgentSettings. For example:

```python
agent = AgentSettings(
    agent_llm="ollama/llama3.2",
    agent_llm_config=local_llm_config,
    index=IndexSettings(
        paper_directory=".",
        index_directory=".",
        manifest_file="./manifest.csv",
        concurrency=1,
    ),
    timeout=600,
    search_count=1
)
```

Then pass agent to Settings as usual. You should not pass paper_directory directly to Settings or AgentSettings. This is a known misalignment between the warning and the actual code—see [this issue](https://github.com/Future-House/paper-qa/issues/782) for confirmation.
