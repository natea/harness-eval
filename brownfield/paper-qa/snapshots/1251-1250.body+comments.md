This error happens because the config for "search_only_clinical_trials" includes chunk_size and overlap fields under parsing, but the current paper-qa version expects only specific fields there and forbids any extras. If these fields are present but not recognized by the ParsingSettings model, Pydantic will throw a validation error like the one you’re seeing. This is likely due to a mismatch between the config file and the latest code expectations, which has happened with other settings in recent updates as well [see discussion](https://github.com/Future-House/paper-qa/issues/1026).

To fix this, you can try removing the chunk_size and overlap fields from the parsing section of your config, or if you’re using the built-in config, copy it locally, edit out those fields, and then load it with Settings.from_name pointing to your edited config. This should let you proceed without the validation error.

If you want to keep custom chunking, make sure the fields you use in parsing match exactly what the current ParsingSettings model allows. If you’re not sure, you can check the latest source for allowed fields [here](https://github.com/Future-House/paper-qa/blob/8221e3cf8b7ff7b2485cd9e05e44387dab183a0a/paperqa/settings.py#L156-L865).

Let me know if you want a quick example of how to patch the config!

You're right, you are using the built-in settings. The reason you're seeing this error is likely a version mismatch between the code and the built-in config files: the built-in config for `"search_only_clinical_trials"` does include `chunk_size` and `overlap` under `parsing`, which should be valid according to the current code, but if your installed package and config files are out of sync, Pydantic will complain about "extra fields" like this [see code reference](https://github.com/Future-House/paper-qa/blob/8221e3cf8b7ff7b2485cd9e05e44387dab183a0a/paperqa/configs/search_only_clinical_trials.json#L15-L19).

To fix this, try the following:
1. Make sure you have a clean, up-to-date install of paper-qa (e.g., run `pip install --upgrade --force-reinstall paperqa` in your Colab).
2. If you still get the error, it's possible an old config is being picked up from your user directory. Try deleting any `~/.config/paperqa/settings/search_only_clinical_trials.json` file if it exists, so the package uses the bundled config.

If the problem persists, as a workaround, you can copy the built-in config, remove the `chunk_size` and `overlap` fields, and load it as a custom config. Let me know if you want a quick step-by-step for that!
