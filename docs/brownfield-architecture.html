harness-eval · Brownfield Track

Testing coding-agent harnesses on real merged PRs: each issue is rewound to before the fix, solved in a sealed repo, and graded with the PR's hidden tests, without letting the agent see the answer.

How a task is made

  • • Take a merged PR that closes an issue opened before the fix work began
  • • Rewind the issue to T* and seal the repo at the PR's base commit
  • • Validate offline: the gold patch must turn hidden tests from failing to passing (F2P) without breaking others (P2P), twice
  • • Label how much each issue body/comment leaks the fix (LLM + blind human review)

How a harness is scored

  • • Every candidate gets the same sealed repo, ISSUE.md variant and base prompt
  • • Its diff vs base is captured; test files and pytest config are reset to base
  • • Hidden tests.patch applied; resolved only if every F2P and P2P test passes
  • • Results reported by leak stratum and paired across issue variants
