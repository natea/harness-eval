# What parameter determines top k sources?

_Opened by @jacknguyen0810 on 2025-06-10_

Labels: question

Hi, 

In the Language Agents Achieve Superhuman Synthesis of Scientific Knowledge paper, the top-k sources can be varied, although set to 30 in the paper. 

I want to vary this parameter. However, it is unclear which parameter this is. 

I believe the 

```python
AnswerSettings(evidence_k=30)
```

is the appropriate parameter. 

However, in the README is says the way to vary this parameter is 
```python
settings = Settings()
settings.answer.k = 30
```

And the paper says that the parameter is:
```python
consider_sources = 30
```

Please could someone confirm which is the correct way to vary the top-k parameter?

## Discussion

**@dosubot** (2025-06-10):

<!-- Answer -->
The correct parameter to control the top-k sources is evidence_k in AnswerSettings. You can set it either when creating the settings object, like AnswerSettings(evidence_k=30), or by using settings.answer.evidence_k = 30 after instantiating Settings. The README sometimes refers to settings.answer.k as a shortcut, but the actual field in the code is evidence_k. There is no parameter called consider_sources in the codebase—this does not exist in the implementation or documentation. For reference, see the [AnswerSettings definition](https://github.com/Future-House/paper-qa/blob/0e493ba75553a43d2066335a46c49f1442772601/paperqa/settings.py) and the [settings tutorial](https://github.com/Future-House/paper-qa/blob/0e493ba75553a43d2066335a46c49f1442772601/docs/tutorials/settings_tutorial.md).
