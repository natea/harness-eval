# open_dataset raises PermissionError during engine detection for a local Zarr directory on Windows

_Opened by @chudlerk on 2026-10-23_

Labels: bug, topic-backends

### What happened?

On Windows, `xr.open_dataset()` raises `PermissionError` for a readable local Zarr directory during engine detection. The traceback comes from the netCDF4 backend trying to open the directory as a file.

Specifying `engine="zarr"` or using `xr.open_zarr()` works.

### Expected behavior

Automatically detect and open the Zarr store.

### Minimal example

```Python
from pathlib import Path
from tempfile import TemporaryDirectory

import xarray as xr

with TemporaryDirectory() as temporary_directory:
    store = Path(temporary_directory) / "example.zarr"
    xr.Dataset({"temperature": ("time", [1.0, 2.0, 3.0])}).to_zarr(
        store, zarr_format=2
    )

    with xr.open_dataset(store, engine="zarr", chunks={}) as dataset:
        assert dataset.temperature.compute().values.tolist() == [1.0, 2.0, 3.0]

    with xr.open_zarr(store, chunks={}) as dataset:
        assert dataset.temperature.compute().values.tolist() == [1.0, 2.0, 3.0]

    xr.open_dataset(store, chunks={})  # Raises PermissionError on Windows
```
