# Type checking fails for DataArrayCoarsen methods

_Opened by @Antyos on 2023-09-01_

Labels: bug, topic-typing

### What happened?

Pylance doesn't recognize method calls on `DataArrayCoarsen` such as `.mean()` or `.sum()`

For the code:

```python
da.coarsen().mean()
```

I get the following error squiggle:

> Cannot access member "mean" for type "DataArrayCoarsen"
  Member "mean" is unknown _Pylance ([reportGeneralTypeIssues](https://github.com/microsoft/pyright/blob/main/docs/configuration.md#reportGeneralTypeIssues))_

**@headtr1ck** (2023-09-13):

Also happens with mypy.
Reason is that the class `xarray.core.ops.IncludeReduceMethods` injects these methods dynamically from the `duck_array_ops` module.

The injections methods are only used in these IncludeXX classes and they are not too easy to follow.
I'm not sure that the saved code repetitions are worth the inconvenience.

Basically we have to options to fix this:

1. Add an `ops.pyi` file and only add the functions there
2. Change the injections by "hardcoded" function definitions
