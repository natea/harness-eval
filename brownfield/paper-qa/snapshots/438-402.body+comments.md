To name an index and execute a search over the index using the Python module in the `paperqa` library, you can use the `SearchIndex` class. Here is an example of how to do this:

1. **Create and name the index:**

```python
from paperqa.agents.search import SearchIndex
from paperqa.settings import Settings

# Create a SearchIndex instance with a custom name
index_name = "nanomaterials"
settings = Settings()  # Load or configure your settings as needed
search_index = SearchIndex(index_name=index_name, settings=settings)

# Initialize the directory for the index
await search_index.init_directory()
```

2. **Add documents to the index:**

```python
# Example document to add
index_doc = {
    "file_location": "path/to/document",
    "body": "This is the content of the document."
}

# Add the document to the index
await search_index.add_document(index_doc)
```

3. **Execute a search over the index:**

```python
# Perform a search query
query = "thermoelectrics"
results = await search_index.query(query, top_n=10)

# Print the search results
for result in results:
    print(result)
```

This code snippet demonstrates how to name an index, add documents to it, and execute a search query using the `paperqa` library's Python module. The `Settings` class is used to configure the settings for the `SearchIndex` <sup>[[1]](https://github.com/Future-House/paper-qa/blob/main/paperqa/agents/search.py)</sup><sup>[[2]](https://github.com/Future-House/paper-qa/blob/main/paperqa/agents/__init__.py)</sup>.

To use a previous `ask` object index to execute a search without adding each document individually, you can use the `search` command with the `--index` option set to `answers`. This allows you to search the index of previous answers.

Here is how you can do it:

```sh
paperqa search --index answers "your search query"
```

This command will search the index of previous answers for the specified query <sup>[[1]](https://github.com/Future-House/paper-qa/blob/main/paperqa/agents/__init__.py)</sup>.

To execute a search using a previous `ask` object index in Python, you can use the `ask` function with the `Settings` object to reference the existing index. Here is an example:

```python
from paperqa import Settings, ask

# Define your query and settings
query = "What manufacturing challenges are unique to bispecific antibodies?"
settings = Settings(paper_directory="path/to/your/index_directory")

# Execute the search
answer = ask(query, settings=settings)

# Print the answer
print(answer)
```

In this example, the `paper_directory` parameter in the `Settings` object is set to the directory where your index is stored. This allows the `ask` function to reference the existing index and execute the search <sup>[[1]](https://github.com/Future-House/paper-qa/blob/main/README.md)</sup><sup>[[2]](https://github.com/Future-House/paper-qa/blob/main/paperqa/agents/__init__.py)</sup>.

**@mskarlin** (2024-09-14):

hey @ivanhigueram -- you should be able to find all your indexes in the `PQA_HOME` directory (defaults to `~/.pqa/indexes/`), you can see the names for each of them there. All answers (no matter from where they originated) will go into the `answers` index, which you can also search via the `search_query ` function. In that case, it'll return `Answer` objects with relevant details for each answer. 

If you have several paper indexes, and you're trying to work out which goes with your settings of interest, just make a new `Settings` object with the paper directory and settings that you previously used and then do: `settings.get_index_name()` -- it'll tell you the name of the index.
